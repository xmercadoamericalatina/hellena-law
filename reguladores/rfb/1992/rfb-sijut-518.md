# Ato Declaratório CSAR nº 5, de 20 de fevereiro de 1992

O ato não possui ementa. Ver íntegra

O COORDENADOR DO SISTEMA DE ARRECADAÇÃO, no uso de suas atribuições, Declara:

1\. O campo 04 do Documento de Arrecadação de Receitas Federais-DARF, para pagamento da Autorização para Internação Hospitalar será preenchido com o código 2076.

2\. A receita recolhida sob este código será classificada sob o código DTN 213-AUTORIZAÇÃO PARA INTERNAÇÃO HOSPITALAR.

LÚCIA BORELLI NORONHA Responsável pelo Expediente
