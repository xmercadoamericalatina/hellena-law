# Ato Declaratório Executivo Cotec nº 1, de 8 de abril de 2014

Estabelece os procedimentos para acesso, via a versão 7 do sistema operacional Windows, aos sistemas aduaneiros desenvolvidos na linguagem de programação Visual Basic.

A COORDENADORA – GERAL DE TECNOLOGIA DA INFORMAÇÃO, no uso das atribuições que lhe conferem o Regimento Interno da Secretaria da Receita Federal do Brasil, aprovado pela Portaria MF nº 203, de 14 de maio de 2012, e tendo em vista a descontinuidade do serviço de suporte da empresa Microsoft ao sistema operacional Windows XP, RESOLVE:

**Art. 1º** Os sistemas aduaneiros desenvolvidos na linguagem de programação Visual Basic poderão ser acessados via a versão 7 do sistema operacional Windows através de máquina virtual XP (XP mode).

**Art. 2º** Esta Portaria entra em vigor na data de sua publicação.

CLAUDIA MARIA DE ANDRADE
