# Solução de Consulta Diana/SRRF06 nº 4, de 7 de março de 2014

ASSUNTO: Classificação de Mercadorias EMENTA: 7326.90.90 - Caixas para ferramentas em geral (para ferramentas com suporte para parafusos; para ferramentas, furadeira e lixadeira, com suporte para parafusos; para furadeira; para ferramentas e furadeira com suporte para parafusos; para serra de mármore; para ferramentas com uma ou duas gavetas; e para ferramentas baú com suporte para parafusos) de aço carbono, cujo o processo de produção é por meio de forjagem, estampagem, dobra em dobradeira / prensa e solda, fabricante Metalúrgica Ouro de Minas Ltda.
