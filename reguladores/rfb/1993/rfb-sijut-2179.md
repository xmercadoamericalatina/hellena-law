# Ato Declaratório SRF nº 65, de 24 de maio de 1993

"Declara os valores de ressarcimento dos selos de controle dos cigarros."

O SECRETÁRIO DA RECEITA FEDERAL, no uso da delegação de competência conferida pela Portaria MF nº 678, de 22 de outubro de 1992,

Declara que os valores de ressarcimento dos selos de controle, por unidade, relativos aos cigarros classificados no código TIPI 2402.20.9900, são os seguintes:

1) Cia. de Cigarros Souza Cruz

Classe A: Cr$ 925,16

Classe B: Cr$ 1.131,20

Classe C: Cr$ 1.292,80

Classe D: Cr$ 1.454,40

Classe E: Cr$ 1.656,40

Classe F: Cr$ 1.858,40

Classe G: Cr$ 2.100,80

Vigência: a partir de 09/05/93

2) Philip Morris Marketing S.A.

Classe A: Cr$ 929,20

Classe B: Cr$ 1.131,20

Classe C: Cr$ 1.292,80

Classe D: Cr$ 1.454,40

Classe E: Cr$ 1.656,40

Classe F: Cr$ 1.858,40

Classe G: Cr$ 2.092,72

Vigência: a partir de 10/05/93
