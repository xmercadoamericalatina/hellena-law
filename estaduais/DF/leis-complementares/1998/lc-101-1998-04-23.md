# Lei Complementar nº 101, de 23/04/1998

**LEI COMPLEMENTAR Nº 101, DE 23 DE ABRIL DE 1998**

(Autor do Projeto: Deputado Distrital José Eudes)

Transforma em comerciais as vias públicas que especifica, localizadas na Região Administrativa de Ceilândia - RA IX.

O GOVERNADOR DO DISTRITO FEDERAL, FAÇO SABER QUE A CÂMARA LEGISLATIVA DO DISTRITO FEDERAL DECRETA E EU SANCIONO A SEGUINTE LEI:

**Art. 1°** - Ficam transformadas em comerciais as seguintes vias públicas da Região Administrativa de Ceilândia - RA IX:

I - Via M1 - Ceilândia Sul - Ceilândia Norte;

II - Via M2 - Ceilândia Sul - Ceilândia Noite;

III - Via M3 - Ceilândia Sul - Ceilândia Noite;

IV - Via N1 - Guanroba - Ceilândia Oeste;

V - Via N2 - Guanroba - Ceilândia Oeste;

VI - Via N3 - Guanroba - Ceilândia Oeste;

VII - Via N4 - Nova Guanroba - Nova Ceilândia;

VIII - Via MN1 - Centro;

IX - Via MN2 - Ceilândia Sul - Ceilândia Noite-Guariroba-Ceilândia Oeste;

X - Via MN3 - Ceilândia Noite-Ceilândia Oeste-Setor O-Expansão-P Norte;

XI - Via Centro Norte - Ceilândia Sul- Guariroba-P Sul;

XII - Via PI - Nova Guanroba- P Sul-Nova Ceilândia-P Norte;

XIII - Via P2 - P Sul-P Norte;

XIV - Via P3-PSul-P Noite;

XV - Via P4 - P Sul;

XVI - Via P5 - P Sul;

XVII - Via O1 - Setor O;

XVIII- Via O2 -Setor O;

XIX - Via O3 -Setor O;

XX - Via O4 - Setor O;

XXI - Via O5 - Setor O - Expansão;

XXII - Via O6 - Expansão;

XXIII - Via O7 - Expansão;

XXIV - Via O6-O7 - Expansão;

XXV - Via O8 - Expansão-Setor de Indústrias-QNQ;

XXVI - Via 1 - Setor de Indústrias-QNQ-QNR;

XXVII - Via 2 - Setor de Indústrias.

**Art. 2º** - Fica permitido o uso comercial nos lotes frontais às vias de que trata esta Lei Complementar.

**Art. 3°** - Esta Lei Complementar entra em vigor na data de sua publicação.

**Art. 4°** - Revogam-se as disposições em contrario.

**Brasília, 23 de abril de 1998**

**110° da República e de Brasília**
