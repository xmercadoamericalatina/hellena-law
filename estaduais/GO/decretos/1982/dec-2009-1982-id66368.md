# Decreto nº 2.009, de 04/02/1982

**GOVERNO DO ESTADO DE GOIÁS Gabinete Civil da Governadoria Superintendência de Legislação.**

DECRETO Nº 2.009, DE 04 DE FEVEREIRO DE 1982.

Institui funções gratificadas na SECRETARIA DE MINAS, ENERGIA E TELECOMUNICAÇÕES.

O GOVERNADOR DO ESTADO DE GOIÁS, no uso de suas atribuições constitucionais, tendo em vista o que consta do processo nº 2100-00267/82 e nos termos do art. 42, parágrafo único, da Lei nº 6.725, de 20 de outubro de 1967,

DECRETA:

**Art. 1º** - Ficam instituídas, na Secretaria da Minas, Energia e Telecomunicações e a partir de 1º de janeiro de 1982, as seguintes funções gratificadas:

| I - | NA CHEFIA DE GABINETE: |  |
| --- | --- | --- |
|  | 01 (uma) de Secretária | FG-3 |
|  | 01 (uma) de Chefe dos Serviços de Relações Públicas | FG-1 |
| II - | NO DEPARTAMENTO DE ADMINISTRAÇÃO: |  |
|  | 01 (uma) de Secretária | FG-3 |
|  | 01 (uma) de Chefe da Divisão Financeira | FG-1 |
|  | 01 (uma) de Chefe da Divisão de Serviços Gerais | FG-1 |
| III - | NA COORDENAÇÃO DE PLANEJAMENTO: |  |
|  | 01 (uma) de Secretária | FG-3 |
|  | 01 (uma) de Chefe de Núcleo de Programação | FG-1 |
|  | 01 (uma) de Chefe de Núcleo de Controle e Supervisão | FG-1 |
| IV - | NA COORDENAÇÃO DE RECURSOS ENERGÉTICOS: |  |
|  | 01 (uma) de Secretária | FG-3 |
|  | 01 (uma) de Chefe do Núcleo de Análise | FG-1 |
|  | 01 (uma) de Chefe de Programas Setoriais | FG-1 |
| V - | NA COORDENAÇÃO DE RECURSOS MINERAIS: |  |
|  | 01 (uma) de Secretária | FG-3 |
|  | 01 (uma) de Chefe do Núcleo de Fomento Mineral | FG-1 |
|  | 01 (uma) de Chefe do Núcleo de Economia Mineral | FG-1 |

**Parágrafo único** - A designação, pelo Secretário de Minas, Energia e Telecomunicações, para função prevista neste artigo importará para atribuição automática da respectiva gratificação.

**Art. 2º** - Este decreto entrará em vigor na data de sua publicação, retroagindo porém os seus efeitos a 1º de janeiro de 1982, revogadas as disposições em contrário.

PALÁCIO DO GOVERNO DO ESTADO DE GOIÁS, em Goiânia, 04 de fevereiro de 1982, 94º da República.

ARY RIBEIRO VALADÃO  
Wolney Wagner de Siqueira  
Ibsen Henrique de Castro

(D.O. de 10-02-1982)
