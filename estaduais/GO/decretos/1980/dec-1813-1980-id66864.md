# Decreto nº 1.813, de 22/05/1980

**GOVERNO DO ESTADO DE GOIÁS Gabinete Civil da Governadoria Superintendência de Legislação.**

DECRETO Nº 1.813, DE 22 DE MAIO DE 1980.  
- Vide o Decreto nº 2.385/84.

Fixa os valores das custas e emolumentos devidos pelos atos de registro do comércio e afins, praticados pela Junta Comercial do Estado de Goiás e dá outras providências.

O GOVERNADOR DO ESTADO DE GOIÁS, no uso de suas atribuição que lhe confere o art. 2º da Lei nº. 7.351, de 30 de junho de 1971, e tendo em vista o que consta do processo nº. 1300-01831/80,

DECRETA:

**Art. 1º** - As custas e emolumentos devidos pelos Atos de Registro de Comercio e Afins, praticados pela Junta Comercial do Estado de Goiás, serão cobradas de acordo com os valores fixados neste decreto, abrangendo:

I - ARQUIVAMENTO

II - REGISTRO

III - MATRICULA OU HABILITAÇÃO

IV - FISCALIZAÇÃO

V - CADASTRO

VI - PUBLICAÇÃO

VII - AUTENTICAÇÃO

**Art. 2º** - As custas de arquivamento incidem;

| I - Nos Atos Constitutivos de Sociedades Anônimas | Cr$ 4.000,00 |
| --- | --- |
| II - Nas Atas Assembléias Gerais | Cr$ 3.000,00 |
| III - Nas Atas de Reuniões de Diretoria | Cr$ 2.500,00 |
| IV - Nos Contratos e Distratos Sociais | Cr$ 3.500.00 |
| V - Nas Alterações Contratuais | Cr$ 3.000,00 |
| VI - Nas Aberturas de Filiais - (Por Filial) | Cr$ 2.500,00 |
| VII - Na Proteção do Nome Comercial | Cr$ 1.000,00 |
| VIII - Jornais, Escrituras de Emancipações de menores e Instrumentos de Mandato | Cr$ 1.000,00 |
| IX - Nos Documentos não Especificados | Cr$ 800,00 |
| Art. 3º - As custas de Registros das Declarações de Firmas incidem sobre as firmas e serão cobradas por ocasião: |  |
| I - Da Constituição | Cr$ 2.500,00 |
| II - Das Anotações | Cr$ 2.000,00 |
| III - Do Cancelamento | Cr$ 1.500,00 |
| Art. 4º - As custas de matrícula ou de habilitação serão cobradas: |  |
| I - PARA TRADUTORES E INTÉRPRETES COMERCIAIS: |  |
| a) Matricula no Cargo de Tradutor e Intérprete | Cr$ 3.000,00 |
| b) Cancelamento de Matrícula | Cr$ 1.500,00 |
| II - PARA LEILOEIROS: |  |
| a) Título de Nomeação | Cr$ 5.000,00 |
| b) Título de Nomeação de Preposto | Cr$ 3.000,00 |
| c) Cancelamento de Título | Cr$ 1.500,00 |
| III - PARA GERENTE: |  |
| a) Carta de Gerente | Cr$ 2.000,00 |
| b) Cancelamento | Cr$ 1.000,00 |
| IV - PARA TRAPICHEIROS, ADMINISTRADORES FIEIS DE DEPÓSITO OU ARMAZÉM: |  |
| a) Nomeação | Cr$ 3.000,00 |
| b) Cancelamento | Cr$ 1.500,00 |
| Art. 5º - As custas de fiscalização serão cobradas: |  |
| I - AOS ARMAZÉNS GERAIS, ANUALMENTE: |  |
| a) Por Empresa (Matriz) | Cr$ 3.000,00 |
| b) Por Agencia ou Filial | Cr$ 3.000,00 |
| II - AOS LEILOEIROS: |  |
| a) Por Leilão efetuado | Cr$ 500,00 |
| Art. 6º - As custas de Cadastro, no valor de Cr$ 500,00 ( quinhentos cruzeiros), serão cobradas de toda Sociedade Comercial ou Firma Individual, por ato praticado. |  |
| Art. 7º - As custas de Publicação, no valor Cr$ 500,00 (quinhentos cruzeiros), incidirão sobre todo ato cuja publicação será exigida. |  |
| Art. 8º - As custas de Autenticação serão cobradas: |  |
| I - Por Livro Mercantil em Blocos de Fichas Sanfonadas. | Cr$ 200,00 |
| II - POR CONJUNTO DE FICHAS AVULSAS: |  |
| a) Até 200 fichas | Cr$ 300,00 |
| b) Acima de 200 Fichas, por lote adicional de até 100 Fichas | Cr$150,00 |
| III - Por Documentos | Cr$ 50,00 |
| Art. 9º - Cobrar-se-ão emolumentos sobre: |  |
| I - Busca prévia ou Consultas a Documentos | Cr$ 150,00 |
| II - CERTIDÃO: |  |
| a) Por Folha Fotocopiada (incluindo a Fotocópia e a Autenticação) | Cr$ 100,00 |
| b) Por Folha Datilografada | Cr$ 300,00 |
| III - Oposição ou Recurso | Cr$ 5.000,00 |
| IV - Cumprimento de Exigência | Cr$ 1.000,00 |
| V - Desarquivamento de Processo | Cr$ 500,00 |
| VI - Desistência de Processos ou Documentos em Andamento na Junta Comercial | Cr$ 500,00 |
| VII - Pedido de Reconsideração ás Turmas | Cr$ 1.000,00 |
| VIII - CARTEIRA DO EXERCÍCIO PROFISSIONAL: |  |
| a) Por Expedição | Cr$ 1.000,00 |
| b) Por Revalidação | Cr$ 500,00 |

**Art. 10** - Os valores das taxas e emolumentos fixados por este decreto serão reajustados, por ato do Presidente da Junta Comercial do Estado de Goiás, sempre que ocorrer variação no valor da Unidade Fiscal de Referencia (UFR), desprezadas as frações de centavos.

**Art. 11** - O produto de arrecadação das custas emolumentos será aplicado na manutenção e custeio dos serviços da Junta Comercial do Estado de Goiás.

**Art. 12** - Este decreto entrará em vigor na data de sua publicação, revogadas as disposições em contrário.

PALÁCIO DO GOVERNO DO ESTADO DE GOIÁS, em Goiânia, 22 de maio de 1980, 92º da República.

ARY RIBEIRO VALADÃO  
Hugo Cunha Goldfeld
