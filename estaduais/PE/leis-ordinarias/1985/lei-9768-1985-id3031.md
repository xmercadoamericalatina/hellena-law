# Lei Ordinária n° 9.768

**LEI Nº 9.768, DE 5 DE DEZEMBRO DE 1985.**

Transfere Subvenção.

Faço saber que o Poder Legislativo decreta e eu promulgo a seguinte Lei:

| --- | --- |

| OLINDA |  |
| --- | --- |
| Colégio Imaculado Coração de Maria | Cr$ 100.000 |

| VITÓRIA DE SANTO ANTÃO |  |
| --- | --- |
| Faculdade de Formação de Professores | Cr$ 70.000 |
| Colégio Nossa Senhora das Graças | Cr$ 100.000 |

| RECIFE |  |
| --- | --- |
| Escola São Jorge | Cr$ 100.000 |
| Colégio Porto Carreiro | Cr$ 80.000 |

| OLINDA |  |
| --- | --- |

| Escola Ana Augusto | Cr$ 200.000 |

| GOIANA |  |
| --- | --- |

**Art. 3º** Revogam-se as disposições em contrário.

Assembléia Legislativa do Estado de Pernambuco, em 5 de dezembro de 1985.
