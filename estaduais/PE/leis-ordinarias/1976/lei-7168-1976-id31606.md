# Lei Ordinária n° 7.168

**LEI Nº 7.168, DE 3 DE AGOSTO DE 1976.**

Transfere Subvenção

O PRESIDENTE DA ASSEMBLEIA LEGISLATIVA DO ESTADO DE PERNAMBUCO:

Faço saber que o Poder Legislativo decreta e eu promulgo a seguinte Lei:

**Art. 1º** Fica transferida a importância de setenta e quatro mil cruzeiros (Cr$ 74.000,00), discriminada no Adendo “C” do Orçamento Geral do Estado, exercício de 1976, em nome da Sociedade Ouricuriense de Amparo à Maternidade e à Infância, sediada no município de Ouricuri, para as entidades abaixo relacionadas, a fim de custear bolsas de estudo:

| Escola Normal Dom Malan - Araripina | Cr$ 7.000,00 |
| --- | --- |
| Colégio Paulo VI (Escola Técnica de Comércio) - Araripina | Cr$ 4.000,00 |
| Ginásio Francisco Alves - Mirandiba | Cr$ 10.000,00 |
| Faculdade de Ciências Médicas (FESP) - Recife | Cr$ 4.000,00 |
| Faculdade de Odontologia (FESP) - Recife | Cr$ 2.000,00 |
| Faculdade de Filosofia do Recife | Cr$ 2.000,00 |
| Universidade Católica de Pernambuco - Recife | Cr$ 5.000,00 |
| Colégio Virgem Poderosa - Recife | Cr$ 800,00 |
| Colégio Esultra - Recife | Cr$ 1.000,00 |
| Colégio Carneiro Leão - Recife | Cr$ 3.400,00 |
| Colégio Nóbrega - Recife | Cr$ 2.000,00 |
| Curso e Colégio Radier - Recife | Cr$ 9.000,00 |
| Colégio Esuda - Recife | Cr$ 6.000,00 |
| Colégio Nossa Senhora do Carmo - Recife | Cr$ 1.000,00 |
| Colégio Independência (Vila do IPSEP) - Recife | Cr$ 500,00 |
| Colégio Boa Vista - Recife | Cr$ 4.000,00 |
| Colégio Salesiano - Recife | Cr$ 1.500,00 |
| Sociedade Cultural Brasil-Estados Unidos - Recife | Cr$ 1.000,00 |
| Instituto Profissional Maria Auxiliadora - Recife | Cr$ 2.000,00 |
| União Curso - Recife | Cr$ 6.800,00 |
| Curso Osvaldo Cruz – Recife | Cr$ 1.000,00 |

**Art. 2º** A presente Lei entrará em vigor na data de sua publicação, revogadas as disposições em contrário.

Assembleia Legislativa do Estado de Pernambuco, em 3 de agosto de 1976.

CARLOS VERAS

Presidente
