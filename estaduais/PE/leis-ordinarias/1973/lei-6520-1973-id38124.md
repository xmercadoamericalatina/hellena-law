# Lei Ordinária n° 6.520

**LEI Nº 6.520, DE 12 DE JUNHO DE 1973.**

Transfere subvenções.

O PRESIDENTE DA ASSEMBLÉIA LEGISLATIVA DO ESTADO DE PERNAMBUCO:

Faço saber que o Poder Legislativo decreta e eu promulgo a seguinte Lei:

**Art. 1º** Ficam transferidas as subvenções abaixo discriminadas, constantes do Orçamento Geral do Estado, para o corrente exercício (Adendo “C”), todas localizadas nesta Capital, no valor total de Cr$ 10.450,00 (dez mil, quatrocentos e cinquenta cruzeiros):

| Colégio Carneiro Leão | Cr$ 1.000,00 |
| --- | --- |
| Colégio Marietinha Verçosa | Cr$ 600,00 |
| Movimento de Ação Social de Pernambuco (MASPE) | Cr$ 1.700,00 |
| Ginásio do Instituto Nossa Senhora do Carmo | Cr$ 400,00 |
| Colégio Técnico Vila Mauricéia | Cr$ 300,00 |
| Escolinha de Arte do Recife | Cr$ 300,00 |
| Colégio Manoel Bandeira | Cr$ 300,00 |
| Colégio Moderno | Cr$ 300,00 |
| Ginásio Guararapes | Cr$ 300,00 |
| Colégio Pinto Júnior | Cr$ 300,00 |
| Colégio Nóbrega | Cr$ 500,00 |
| Colégio Salesiano | Cr$ 2.550,00 |
| Colégio Vera Cruz | Cr$ 400,00 |
| Curso Radier | Cr$ 1.200,00 |
| Colégio Pedro Álvares Cabral | Cr$ 300,00 |
| TOTAL | Cr$ 10.450,00 |

**Art. 2º** São as seguintes as entidades beneficiadas com as transferências de que trata o artigo anterior:

| Colégio Americano Batista | Cr$ 1.000,00 |
| --- | --- |
| Colégio Independência | Cr$ 900,00 |
| Colégio Bandeirante | Cr$ 400,00 |
| Colégio Pôrto Carreiro | Cr$ 300,00 |
| Ginásio São Judas Tadeu | Cr$ 400,00 |
| Colégio Técnico Luiz Freire | Cr$ 300,00 |
| Colégio da Boa Vista | Cr$ 300,00 |
| Colégio Vital Brasil | Cr$ 600,00 |
| Colégio Nossa Senhora dos Remédios | Cr$ 300,00 |
| Instituto São Luiz | Cr$ 4.050,00 |
| Colégio Padre Abranches | Cr$ 600,00 |
| Colégio São Pedro | Cr$ 300,00 |
| Colégio São Bento - Olinda | Cr$ 1.000,00 |
| TOTAL | Cr$ 10.450,00 |

**Art. 3º** A presente lei entrará em vigor na data de sua publicação, revogadas as disposições em contrário.

Assembléia Legislativa do Estado de Pernambuco, em 12 de Junho de 1973.

ÊNIO PESSOA GUERRA
