# Lei Ordinária n° 5.775

**LEI Nº 5.775, DE 18 DE DEZEMBRO DE 1965.**

Extingue e cria cargos no Serviço Civil do Poder Executivo.

O GOVERNADOR DO ESTADO DE PERNAMBUCO:

Faço saber que a Assembleia Legislativa decretou e eu sanciono a seguinte Lei:

**Art. 1º** São criados no Quadro Permanente de Pessoal do Serviço Civil do Poder Executivo os seguintes cargos:

| Serviço: EDUCAÇÃO |  |  |
| --- | --- | --- |
| Grupo Ocupacional: Magistério Primário da Capital - 3.02 |  |  |
| Classe: em série |  |  |
| Cargos: |  |  |
| Dirigente de Grupo Escolar ou Escola Especial da Capital | 3.02.01.04.J | 45 |
| Grupo Ocupacional: Magistério Primário do Interior - 3.03 |  |  |
| Classe: em série |  |  |
| Cargos: |  |  |
| Dirigente de Grupo Escolar ou Escola Especial do Interior | 3.03.01.04.J | 46 |
| Grupo Ocupacional: Técnico Educacional - 3.08 |  |  |
| Classe: Única |  |  |
| Técnico de Educacional Primária | 3.08.00.03.M | 4 |
| Serviço: TÉCNICO CIENTÍFICO |  |  |
| Grupo Ocupacional: Orientação Educacional - 6.13 |  |  |
| Classe: Única |  |  |
| Orientador Educativo | 6.13.00.01.I | 5 |

(45 cargos de Dirigentes de Grupo Escolar ou Escola Especial da Capital e 46 de Grupo Escolar ou Escola Especial do Interior – extinto pelo art. 4° da Lei n° 5.800, de 1° de junho de 1966.)

**Art. 2°** (REVOGADO) (Revogado pelo art. 5° da Lei n° 5.800 , de 1° de junho de 1966.)

**Art. 3°** (REVOGADO) (Revogado pelo art. 5° da Lei n° 5.800 , de 1° de junho de 1966.)

**Art. 4º** Os atuais cargos de Dirigente de Grupo Escolar ou Escola Especial da Capital ou do Interior passam a denominar-se de Dirigente de Unidade Escolar da Capital ou do Interior, respectivamente.

**Art. 5º** A despesa com a execução da presente lei correrá por conta das disponibilidades financeiras do Estado.

**Art. 6º** A presente lei entrará em vigor na data de sua publicação revogadas as disposições em contrário.

Palácio do Governo do Estado de Pernambuco, em 18 de dezembro de 1965.

PAULO PESSOA GUERRA
