# Lei Ordinária n° 9.397

**LEI Nº 9.397, DE 5 DE DEZEMBRO DE 1983.**

Transfere Subvenção.

O GOVERNADOR DO ESTADO DE PERNAMBUCO:

Faço saber que a Assembléia Legislativa decretou e eu sanciono a seguinte Lei:

**Art. 1º** Fica transferida para o SERVIÇO ASSISTENCIAL DE BEBERIBE - SABE, sediado no Município de Olinda, a importância de $ 215.000,00 (duzentos e quinze mil cruzeiros), parte da dotação discriminada no Adendo ”C” do Orçamento vigente do Estado, em nome das seguintes entidades:

| RECIFE |  |
| --- | --- |
| Colégio Ferroviário do Recife | Cr$ 15.000,00 |
| Colégio Independência | Cr$ 30.000,00 |
| Colégio Marista | Cr$ 20.000,00 |
| Escola Superior de Relações Pública - ESURP | Cr$ 40.000,00 |
| Educandário Anita Garibaldi | Cr$ 10.000,00 |
| Associação Cristã Evangélica | Cr$ 20.000,00 |
| Núcleo Espírita Casa de Jaraguá | Cr$ 20.000,00 |
| OLINDA |  |
| Faculdade de Direito de Olinda | Cr$ 20.000,00 |
| Colégio São Bento | Cr$ 20.000,00 |
| JABOATÂO |  |
| Santuário de Cristo rei | Cr$ 20.000,00 |

**Art. 2º** A presente Lei entrará em vigor na data de sua publicação.

**Art. 3º** Revogam-se as disposições em contrario.

Palácio do Campo das Princesas, em 5 de dezembro de 1983.

ROBERTO MAGALHÃES MELO
