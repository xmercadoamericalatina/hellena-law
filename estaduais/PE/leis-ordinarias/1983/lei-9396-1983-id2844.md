# Lei Ordinária n° 9.396

**LEI Nº 9.396, DE 5 DE DEZEMBRO DE 1983.**

Transfere Subvenção.

O GOVERNADOR DO ESTADO DE PERNAMBUCO:

Faço saber que a Assembléia Legislativa decretou e eu sanciono a seguinte lei:

**Art. 1º** Fica transferida para o Externato Santo Antônio da Cidade, sediado no Município de Caruaru, a importância de Cr$ 100.000,00 (cem mil cruzeiros), parte da dotação discriminada no Adendo “C” do Orçamento Geral do Estado, do corrente exercício, em favor das seguintes entidades:

| CARUARU: |  |
| --- | --- |
| Instituto Corte de Ouro ................................................................................. | Cr$ 10.000,00 |
| Instituto São José ........................................................................................... | Cr$ 10.000,00 |
| Externato 21 de Abril ..................................................................................... | Cr$ 20.000,00 |
| RECIFE: |  |
| Benfica Futebol Clube ................................................................................... | Cr$ 10.000,00 |
| Escola de Samba Labariri .............................................................................. | Cr$ 10.000,00 |
| Clube Carnavalesco Misto Pão da Tarde ...................................................... | Cr$ 10.000,00 |
| Troça Carnavalesca Mista Arrasta Tudo ...................................................... | Cr$ 10.000,00 |
| OLINDA |  |
| Instituto Luiz Negromonte (bolsa de estudo) ................................................ | Cr$ 20.000,00 |

**Art. 2º** A presente Lei entrará em vigor na data de sua publicação.

**Art. 3º** Revogam-se as disposições em contrário.

Palácio do Campo das Princesas, em 5 de dezembro de 1983.

ROBERTO MAGALHÃES MELO

Governador do Estado

SYLENO RIBEIRO PAIVA
