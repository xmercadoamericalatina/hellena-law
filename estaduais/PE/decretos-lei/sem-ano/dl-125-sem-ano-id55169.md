# Decreto-Lei n° 125

**DECRETO-LEI Nº 125, DE 28 DE OUTUBRO DE 1969.**

Autoriza abertura de crédito suplementar.

O GOVERNADOR DO ESTADO, no uso das atribuições que lhe confere o § 1º do artigo 2º do Ato Institucional nº 5, de 13 de dezembro de 1968, tendo em vista o disposto no artigo 1º do Ato Complementar nº 47, de 7 de fevereiro de 1969,

DECRETA:

**Art. 1º** Fica o Poder Executivo autorizado a abrir ao Sub-Anexo 43.11.00 - SECRETARIA DE INTERIOR E JUSTIÇA, o crédito suplementar de NCr$ 26.000,00 (vinte e seis mil cruzeiros novos), destinado ao reforço das dotações orçamentárias abaixo discriminadas:

| 43.11.01 | GABINETE DO SECRETÁRIO |  |

| 3.1.0.00.00 | DESPESAS DE CUSTEIO |  |
| 3.1.1.00.00 | Pessoal | 10,0 |
| 43.11.10 | CASA DE DETENÇÃO DO RECIFE |  |
| 3.0.0.00.00 | DESPESAS CORRENTES |  |
| 3.1.0.00.00 | DESPESAS DE CUSTEIO |  |
