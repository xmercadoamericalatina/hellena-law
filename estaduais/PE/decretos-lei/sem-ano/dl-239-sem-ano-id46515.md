# Decreto-Lei n° 239

**DECRETO-LEI Nº 239, DE 25 DE MARÇO DE 1970.**

Autoriza a abertura de crédito especial, e dá outras providências.

O GOVERNADOR DO ESTADO, no uso das atribuições que lhe confere o § 1º do artigo 2º, do Ato Institucional nº 5, de 13 de dezembro de 1968, e tendo em vista o disposto no artigo 1º do Ato Complementar nº 47, de 7 de fevereiro de 1969,

DECRETA:

**Art. 1°** Fica o Poder Executivo autorizado a abrir crédito especial até o limite de NCr$ 300.000,00 (trezentos mil cruzeiros novos), no Sub-Anexo 43.10.00 - Secretaria de Indústria e Comércio, conforme a discriminação abaixo:

| UNIDADE ORÇAMENTÁRIA | 43.10.01 | GABINETE DO SECRETÁRIO |  |
| --- | --- | --- | --- |
| CLASSIF. DAS DESP. P CAT\| ECONÔMICAS | CLASSIF. DAS DESP. P\| SUB PROGRAMAS |  |  |
| CÓDIGO | ESPECIFICAÇÃO | 08.03 | Valor NCrS |
| 4.0.0.00.00 | Despesas de Capital |  |  |
| 4.3.0.00.00 | Transferências de Capital |  |  |
| 4.3.5.00.00 | Contribuições Diversas |  | 300.000,00 |

**Art. 2º** Os recursos para atender as despesas com o execução do presente Decreto-Lei correrão por conta da redução, em igual importância, da verba abaixo discriminada:

| SUB-ANEXO | 43.10.00 | SECRETARIA IND. E COMÉRCIO |
| --- | --- | --- |
| UNIDADE ORÇAMENTÁRIA | 43.10.01 | GABINETE DO SECRETÁRIO |

| CLASSIF. DAS DESP. P\| CAT ECONÔMICAS | CLASSIF. DAS DESP. P\| SUB PROGRAMAS |  |  |
| --- | --- | --- | --- |
| CÓDIGO | ESPECIFICAÇÃO | 08.02 | Valor NCrS |
| 4.0.0.00.00 | Despesas de Capital |  |  |
| 4.1.0.00.00 | Investimentos |  |  |
| 4.1.5.00.00 | Participação em Constituição ou aumento de Capital de Empresas ou entidades industriais ou agrícolas |  | 300.000,00 |

**Art. 3º** O presente Decreto-Lei entra em vigor na data da sua publicação revogadas as disposições em contrário.

Palácio dos Despachos do Governo do Estado de Pernambuco, em 25 de março de 1970.
