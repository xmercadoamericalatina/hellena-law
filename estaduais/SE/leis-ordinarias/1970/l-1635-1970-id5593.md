# Lei Ordinária nº 1635/1970

**Estado de Sergipe Assembleia Legislativa Secretaria-Geral da Mesa Diretora**

LEI Nº 1.635, DE 28 DE JULHO DE 1970

Autoriza a abertura de crédito especial de CR$ 47.200,00, para fins que especifica e dá outras providências.

O **GOVERNADOR DO ESTADO DE SERGIPE**,

Faço saber que a Assembléia Legislativa do Estado decretou e eu sanciono a seguinte Lei:

**Art. 1º** Fica o Poder Executivo autorizado abrir o crédito especial de Cr$ 47.200,00 (quarenta e sete mil e duzentos cruzeiros), pela Secretaria da Fazenda e em favor do Gabinete do Governador, para reforço, no corrente exercício das verbas orçamentárias abaixo especificadas:

| GABINETE DO GOVERNADOR: |  |
| --- | --- |
| 3.01.02.3.1.2.0- 03.00 |  |
| Gêneros para alimentação e outros correlatos | Cr$ 24.000,00 |
| 3.01.02.3.1.2.0- 05.00 |  |
| Material de limpeza, conservação e desinfecção | Cr$ 2.100,00 |
| 3.01.02.3.1.2.0- 06.00 |  |
| Serviço de divulgação | Cr$ 5.000,00 |
| 3.01.02.3.1.2.0- 08.00 |  |
| Serviço de transportes | Cr$ 7.600,00 |
| 3.01.02.3.1.2.0-13.00 |  |
| Outros serviços de terceiros | Cr$ 1.600,00 |
| 3.01.02.3.1.2.0- 05.00 |  |
| Outros encargos | Cr$ 6.900,00 |
| TOTAL | Cr$ 47.200,00 |

**Art. 2º** A despesa constante da execução do artigo anterior correrá por conta da anulação parcial das rubricas orçamentárias e créditos abaixo discriminados:

| GABINETE DO GOVERNADOR: |  |
| --- | --- |
| 3.01.02.3.1.2.0-04.00 |  |
| Serviço de água, esgoto, iluminação e força | Cr$ 6.400,00 |
| 3.01.02.3.1.2.0-01.00 |  |
| Máquinas, motores e aparelhos | Cr$ 2.500,00 |
| 3.01.02.3.1.2.0-03.00 |  |
| Automóveis, autocaminhões e outros veículos de tração mecânica | Cr$ 27.000,00 |
| Crédito Especial - Decreto nº 1.795 de 9/III/70 |  |
| Auxilio para promoções culturais e estudantis | Cr$ 11.000,00 |

**Art. 3º** Esta Lei entrará em vigor na data de sua publicação, revogadas as disposições em contrário.

Palácio "Olympio Campos", em Aracaju, 28 de julho de 1970, 82º da República.

JOÃO DE ANDRADE GARCEZ

GOVERNADOR DO ESTADO

Este texto não substitui o publicado no D.O.E de 28.07.1970.
