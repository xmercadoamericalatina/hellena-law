# Lei Ordinária nº 1498/1967

**Estado de Sergipe Assembleia Legislativa Secretaria-Geral da Mesa Diretora**

LEI Nº 1.498, DE 21 DE NOVEMBRO DE 1967

Estima a receita e Fixa a Despesa do Estado de Sergipe para o Exercício Financeiro de 1968.

O **GOVERNADOR DO ESTADO DE SERGIPE**,

Faço saber que a Assembleia Legislativa do Estado de Sergipe decretou e eu sanciono a seguinte Lei:

**Art. 1º** A Receita do Estado de Sergipe para o exercício de 1968 é orçada em trinta e quatro milhões, novecentos e sessenta mil cruzeiros novos (NCr$ 34.960.000,00), de acordo com o seguinte desdobramento:

| 1.1 - Receita Tributária |  |  |  |  |

| b) Taxas | 400.000,00 | 20.620.000,00 |  |  |
| 1.2 - Receita Patrimonial |  | 26.000,00 |  |  |
| 1.3 - Receita Industrial |  | 185.000,00 |  |  |
| 1.4 - Transferências Corrente |  | 8.653.500,00 |  |  |
| 1.5 - Receitas Diversas |  | 128.500,00 | 29.613.000,00 |  |
| 2 - RECEITAS DE CAPITAL |  |  |  |  |

| 2.3 - Outras Receitas de Capital |  | 1.000,00 | 5.347.000,00 |  |

**Art. 2º** A despesa para o exercício de 1968 é fixada em NCr$ 34.960.000,00 (trinta e quatro milhões, novecentos e sessenta mil cruzeiros novos) e será realizada de acordo com as especificações constantes das tabelas anexas, que ficam fazendo parte integrante desta Lei, obedecendo o seguinte desdobramento:

| 0 - Governo e Administração Geral | 14.935.560,00 |
| --- | --- |
| 1 - Encargos Gerais | 1.248.098,00 |
| 2 - Recursos Naturais e Agropecuários | 343.186,00 |
| 3 – Energia | 200.000,00 |
| 4 - Transportes e Comunicações | 2.280.000,00 |
| 5 - Industria e Comercio | 94.530,00 |
| 6 - Educação e Cultura | 6.928.359,00 |
| 7 – Saúde | 1.393.973,00 |
| 8 - Trabalho, Previdência e Assistência Social | 7.446.294,00 |
| 9 - Habitação e Serviços Urbanos | 90.000,00 |
| TOTAL: | 34.960.000,00 |

**Art. 3º** Serão organizados e aprovados por ato de Poder Executivo, no prazo de 15 (quinze) dias a contar da data da publicação desta Lei, para cada unidade orçamentária, os quadros analíticos da Despesa, observado o disposto no artigo 15 da Lei nº 4.320, de 17 de março de 1964.

**Parágrafo Único.** Quando necessário e até 31 de outubro, os quadros a que se refere este artigo poderão ser alterados, obedecidos os limites máximos dos recursos fixados para cada elemento da Despesa.

**Art. 4º** A Receita será arrecadada de acordo com as normas e as tabelas previstas no Código Tributário do Estado e demais disposições legais em vigor.

**Art. 5º** Fica o Poder Executivo autorizado a abrir créditos suplementares no decorrer do exercício de 1968, até o limite de 10% (dez por cento) da Receita prevista, na forma dos artigos 7º e 43 da Lei nº 4.320 de 17 de março de 1964, obedecendo as normas orçamentárias, financeiras e de contabilidade em vigor.

**Art. 6º** Por antecipação da Receita do exercício, poderá o Governador do Estado realizar operações de crédito que se fizerem necessárias até o limite de NCr$ 4.000.000,00 (quarenta milhões de cruzeiros novos).

**Art. 7º** Revogam-se as disposições em contrário.

Palácio "Olímpio Campos", Aracaju, 21 de novembro de 1967, 79º da República.

LOURIVAL BAPTISTA

GOVERNADOR DO ESTADO
