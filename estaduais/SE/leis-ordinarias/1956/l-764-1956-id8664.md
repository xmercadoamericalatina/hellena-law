# Lei Ordinária nº 764/1956

**Estado de Sergipe Assembleia Legislativa Secretaria-Geral da Mesa Diretora**

LEI Nº 764, DE 08 DE OUTUBRO DE 1956

Autoriza a abertura, pela Assembléia Legislativa, do crédito suplementar da importância de Cr$ 926.000,00.

O **GOVERNADOR DO ESTADO DE SERGIPE**,

Faço saber que a Assembléia Legislativa do Estado decretou e eu sanciono a seguinte Lei:

**Art. 1º** Fica o poder Executivo autorizado a abrir, pela Assembléia Legislativa, o crédito suplementar da importância de Cr$ 926.000,00 (novecentos e vinte e seis mil cruzeiros), em reforço às seguintes verbas do orçamento vigente:

| Verba 0.10-8.00. - Pessoal Fixo Cr$ |  |  |
| --- | --- | --- |
| Consignação 01 - Vencimento e remuneração em geral | 800.000,00 |  |
| Consignação 03 - Diárias e ajuda de custo | 50.000,00 | 850.000,00 |
| Verba 0.10-8.00.2 - Material Permanente |  |  |
| Consignação 24 - Máquinas de Escritório etc. | 20.000,00 |  |
| Verba 0.10-8.0033 - Material de consumo |  |  |
| Consignação 34 - Material de expediente etc. | 20.000,00 |  |
| Verba 0.10-8.00.4 - Despesas diversas |  |  |
| Consignação 40 - Água, esgoto, aceito, luz e força | 5.000.00 |  |
| Consignação 42 - Despesas de conservação em geral | 4.000,00 |  |
| Consignação 47 - Despesas postais, teleg. e telef. | 2.000,00 |  |
| Consignação 56 - Despesas não especificadas | 25.000,00 | 36.000,00 |

**Art. 2º** A despesa decorrente da presente Lei correrá por conta do excesso de arrecadação que se verificar no corrente exercício.

**Art. 3º** A presente Lei entrará em vigor, depois de sancionada, na data de sua publicação, revogadas as disposições em contrário.

LEANDRO MAYNARD MACIEL

GOVERNADOR DO ESTADO

Este texto não substitui o publicado no D.O.E. 11.10.1956
