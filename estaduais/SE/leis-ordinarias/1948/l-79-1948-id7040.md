# Lei Ordinária nº 79/1948

**Estado de Sergipe Assembleia Legislativa Secretaria-Geral da Mesa Diretora**

LEI Nº 79, DE 22 DE NOVEMBRO DE 1948

Orça a Receita e fixa a Despesa do Estado de Sergipe para o exercício de 1949.

O **GOVERNADOR DO ESTADO DE SERGIPE**,

Faço saber que a Assembléia Legislativa do Estado decretou e eu sanciono a seguinte Lei:

**Art. 1º** A receita do Estado de Sergipe, para o exercício de 1949, é orçada em CR$ 60.000.000,00 (sessenta milhões de cruzeiros) obedecendo à seguinte classificação:

| **I - RECEITA ORDINÁRIA** |  |  |
| --- | --- | --- |
| 1. Receita Tributária |  |  |
| a) Impostos | 45.470.000 |  |
| b) Taxas | 6.530.000,00 | 52.000.00000 |
| 2. Receita Patrimonial |  | 70.00000 |
| 3. Receita Industrial |  | 6.172.0000 |
| Total da Receita Ordinária |  | 58.242.00000 |
| II- RECEITA EXTRAORDINÁRIA |  | 1.758.000 00 |
| **Total Geral da Receita** |  | **60.000.00000** |

**Art. 2º** A Despesa a ser realizada no exercício de 1949, com a satisfação dos encargos do Estado, custeio e manutenção dos serviços públicos estaduais, é fixada em cinqüenta e nove milhões novecentos e vinte e quatro mil duzentos e quarenta cruzeiros (Cr$ 59.924.240,00) e será distribuída do seguinte modo e de acordo com as tabelas discriminadas anexas, que ficam fazendo parte integrante desta Lei:

| 0 - Administração Geral | 6.266.600,00 |
| --- | --- |
| 1 - Exação e fiscalização financeira | 5.530.000,00 |
| 2 - Segurança Pública e Assistência Social | 7.801.880,00 |
| 3 - Educação Pública | 9.947.680,00 |
| 4 - Saúde Pública | 4.890.700,00 |
| 5 - Fomento | 2.107.200,00 |
| 6 - Serviços Industriais | 12.418.000 00 |
| 7 - Dívida Pública | 377.750,00 |
| 8 - Serviços de Utilidade Pública | 3.133.500,00 |
| 9 - Encargos diversos | 7450.93000 |
| Total geral da despesa | 59.924.24000 |

**Art. 3º** Esta Lei entrará em vigor na data de sua publicação, revogadas as disposições em contrário.

Palácio do Governo do Estado de Sergipe, Aracaju, 22 de novembro de 1948, 60º da República.

JOSÉ ROLLEMBERG LEITE

João de Araújo Monteiro

Marcos Ferreira de Jesus

José da Silva Ribeiro Filho
