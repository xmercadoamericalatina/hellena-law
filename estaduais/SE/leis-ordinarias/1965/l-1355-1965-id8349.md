# Lei Ordinária nº 1355/1965

**Estado de Sergipe Assembleia Legislativa Secretaria-Geral da Mesa Diretora**

LEI Nº 1.355, DE 16 DE NOVEMBRO DE 1965

Autoriza a abertura pela Assembléia Legislativa do Estado do Crédito suplementar da importância de Cr$ 25.900.000.

O **GOVERNADOR DO ESTADO DE SERGIPE**,

Faço saber que a Assembléia Legislativa do Estado de Sergipe decretou e eu sanciono a seguinte Lei:

**Art. 1º** É o Poder Executivo autorizado a abrir pela Assembléia Legislativa do Estado, o crédito suplementar da importância de Cr$ 25.900.000 (vinte e cinco milhões e novecentos mil cruzeiros), em reforço às seguintes verbas do orçamento vigente:

| Verba-0.10-01-3.1.1.1. (Pessoal Civil) |  |
| --- | --- |
| Sub-consignação - 1.09 |  |
| Gratificações por serviços extraordinários | $ 5.000.000 |
| Verba-0.10.3.1.2.0. (material de Consumo) |  |
| Sub-consignação - 1.35 |  |
| Material de limpeza, conservação e desinfecção | $ 900.00 |
| Verba-0.10.01.3.1.3.0 (Serviço de terceiros) |  |
| Sub-consignação -152 |  |
| Adaptação e conservação de bens imóveis | $ 10.000.000 |
| Sub-consignação - 1.54 |  |
| Despesas de Asseio | $ 1.000.000 |
| Sub-consignação – 156 |  |
| Despesa com divulgação | $ 2.000,000 |
| Verba-0.10.01.3.1.4.0 (Encargos diversos) |  |
| Sub-consignação -1.80 |  |
| Despesa não especificadas | $ 4.000.000 |
| Verba-0.10.01.4.1.4.0 (Material de Permanente) |  |
| Sub-consignação - 3.33 |  |
| Máquina, móveis e utensílios para escritório | $ 3.000.000 |
| TOTAL | 25.900.000 |

**Art. 2º** As despesas decorrentes da presente Lei, correrão por conta do excesso de arrecadação deste exercício financeiro.

**Art. 3º** Esta Lei entrará em vigor na data da sua publicação, revogadas as disposições em contrário.

Palácio do Governo do Estado de Sergipe, Aracaju, 16 de novembro de 1965, 77º da República.

Sebastião Celso de Carvalho

GOVERNADOR DO ESTADO
