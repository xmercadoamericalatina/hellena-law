# DECRETO Nº 13.909, DE 24 DE MARÇO DE 2014

***(\*) ESTE TEXTO NÃO SUBSTITUI O ORIGINAL PUBLICADO NO DIÁRIO OFICIAL DO ESTADO.***

**ESTADO DE MATO GROSSO DO SUL**

**DECRETO Nº 13.909, DE 24 DE MARÇO DE 2014.**

*AMPLIA AS VAGAS DO CONCURSO PÚBLICO DE PROVAS E TÍTULOS - SAD/SAS/SEJUSP/2013.*

Notas:  
**Publicado no Diário Ofiial nº 8.642, de 25 de março de 2014, página 3.**

O **GOVERNADOR DO ESTADO DE MATO GROSSO DO SUL**, no uso da atribuição que lhe confere o inciso VII do art. 89 da Constituição Estadual,  
  
**DECRETA: Art. 1º** As vagas do Concurso Público de Provas e Títulos - SAD/SAS/SEJUSP/2013 ficam ampliadas no quantitativo de 38 (trinta e oito) vagas distribuídas para os cargos especificados no seguinte quadro:

| **Municípios** | **Cargo** |  |  |
| --- | --- | --- | --- |
| **Gestor de Ações Socioeducacionais** (Habilitação: Psicologia) | **Agente de Ações Socioeducacionais** |  |  |
| **Sexo** |  |  |  |
| **Masculino** | **Feminino** |  |  |
| Campo Grande | - | 15 | 20 |
| Corumbá | - | - | - |
| Três Lagoas | 3 | - | - |

**Obs: Anexo retificado no Diário Oficial nº 8.643, de 26 de março de 2014, página 1. Parágrafo único.** As vagas, a que se refere o “*caput,*” serão preenchidas por candidatos aprovados em todas as fases, observada a ordem de classificação e o prazo de validade desse Concurso Público.

**Art. 2º** Este Decreto entra em vigor na data de sua publicação.  
  
**CAMPO GRANDE-MS, 24 DE MARÇO DE 2014.**
